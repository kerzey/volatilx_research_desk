## Standing rules proposed

- **A question whose arm label comes from a static repo artifact pins the blob *in force at the window start*, not the blob at the manifest's platform SHA.** The manifest SHA is dated inside the window by construction, so pinning it can import a reclassification the desk could not have known — a look-ahead that no validator would catch, because the file is not a table. Q022 is the first question to read one; it will not be the last (`sp500_sectors.json`, exemplar libraries, any committed config the desk conditions on).
- **A night-level arm whose cut is stated as "m of k" takes the hypothesis's literal denominator; a relative cut is a separate hypothesis.** DP-25 already says the cut is not re-united; the addition is that with an *absolute* cut a short (or long) slate is mechanically pushed toward one arm, so mixing denominators confounds the arm with slate size. Worth stating once so it is not re-derived per question.
- **A two-arm contrast has no demotable arm.** DP-43's demotion clause is written for sub-cells; applied to an arm it would leave a primary endpoint with one side. Q019 and Q022 each decided this separately — the arm shortfall is a floor failure (extension, then DEFERRED), never a demotion to descriptive.
